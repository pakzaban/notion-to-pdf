01

Get the script & install the tools

Download the script above. Open Terminal in its folder and run:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install playwright
python -m playwright install chromium

macOS / Linux commands. On Windows, activate with .venv\Scripts\activate.

02

Connect your Notion parent page

Create a Notion integration with Read content access. On your parent page, use ••• → Connections to add it. Set its token in your terminal:

export NOTION_TOKEN='your-token-here'

Keep your token local. This website never asks for it. Windows PowerShell: $env:NOTION_TOKEN='your-token-here'.

BUILT FOR READING

The useful parts,
kept together.

What comes through?

Nested pages, database entry bodies, headings, lists, checkboxes, code, tables, and images. Text colors and highlights use an approximate Notion light-theme palette. A contents list makes the combined document easier to navigate.

What looks different?

Every Notion page starts on a new PDF page. Columns become a single column and toggles expand. Equations appear as LaTeX source. It’s a readable export, not a pixel-perfect copy of the Notion interface.

What isn’t included?

Attached PDFs, audio, video, and embeds remain links. Database properties and linked database views are not exported, and arbitrary page links aren’t followed. The integration must have access to every page you want included.

Getting a 404 from Notion?

Check that you added your integration to the parent page’s Connections menu and granted Read content access. Use the plain page URL, without Markdown link formatting. The script stops on API errors and warns about unsupported blocks or missing images.
